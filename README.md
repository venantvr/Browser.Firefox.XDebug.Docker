# Browser.Firefox.XDebug.Docker

Firefox conteneurise pour deboguer WordPress et PHP avec XDebug depuis un navigateur isole.

## Structure

| Fichier / Dossier | Role |
|-|-|
| `Dockerfile` | Image Docker Firefox + XDebug |
| `start-browser.sh` | Script de lancement du navigateur |
| `hosts` | Fichier hosts personnalise |
